# CyberShield Day 30 Demo Script

This script describes a factual local demonstration. Use temporary local
credentials only and do not present the demo as public production traffic.

1. Open the frontend landing page and introduce CyberShield's small-business
   security workflow.
2. Open the login/register screen and authenticate with temporary demo
   credentials.
3. Open the dashboard and show business and website context.
4. Create or select a business and website in the local demo environment.
5. Start an authorized scan and show its lifecycle.
6. Open findings and a finding detail view.
7. Show severity, risk context, evidence, and remediation guidance.
8. Open reports and show report listing/download behavior where the demo data
   supports it.
9. Open monitoring and alerts to show scheduled security awareness.
10. Open security activity/audit information.
11. Use the constrained AI assistant if the configured local provider is
    available; otherwise show its deterministic fallback and explain the
    limitation.
12. Demonstrate logout and explain that the client removes the bearer token.
13. Show the local-only deployment and database limitations:
    Caddy/TLS is readiness configuration, and the active SQLite database was
    not migrated.

Do not claim a browser-authenticated end-to-end pass unless the frontend is
configured to the same verified backend instance and the flow is actually
completed.
